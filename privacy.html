Приложение Fonic для Android

Политика конфиденциальности

Действует с 22 сентября 2026 г.

Fonic — диктофон с офлайн-распознаванием речи. Запись, расшифровка, поиск и просмотр записей работают полностью без сети и без передачи содержимого записей на сервер. Эта страница описывает, какие данные приложение обрабатывает и куда они попадают.

Аудиозаписи и расшифровки

Аудиофайлы, текст расшифровок и метаданные записей (название, дата, геометка) хранятся только локально на устройстве, в базе данных приложения. Они не отправляются на сервер автоматически — ни в фоне, ни для синхронизации, ни в составе телеметрии. Приложение передаёт содержимое записи за пределы устройства только по явному действию пользователя: экспорт архива, кнопка «Поделиться» расшифровкой, либо выбор системного приложения для отправки файла. Распознавание речи выполняется на самом устройстве (whisper.cpp) — аудио и текст не отправляются какому-либо облачному сервису распознавания или ИИ.

Микрофон

Доступ к микрофону используется только во время записи, которую запускает пользователь. Аудиопоток не покидает устройство и не прослушивается и не анализируется сторонними сервисами.

Геопозиция

При старте записи приложение может один раз запросить координаты, чтобы привязать к записи адрес и показать её на карте. Координаты передаются системному сервису геокодирования Android, чтобы получить текстовый адрес, и используются для загрузки тайлов карты с OpenStreetMap. Это единственный сценарий, где геоданные уходят в сеть; постоянного отслеживания местоположения приложение не ведёт. Без сети адрес не определяется, а карта показывает только координаты — доступ к геопозиции не обязателен для записи и расшифровки.

Аналитика и отчёты о сбоях

Приложение использует Firebase Analytics и Firebase Crashlytics — техническую телеметрию для понимания стабильности и использования приложения (события навигации, сбои, технические параметры устройства). Текст расшифровок, фрагменты сегментов, названия записей и аудио никогда не попадают в параметры аналитических событий и в отчёты Crashlytics. Также используется Firebase Remote Config для удалённого управления техническими настройками приложения — без передачи содержимого записей.

Реклама

Дополнительные места под записи сверх бесплатного лимита можно получить, посмотрев рекламный ролик (Yandex Mobile Ads); баннер также показывается на главном экране, если не активирована Pro-версия. Рекламный SDK может собирать технические и рекламные идентификаторы устройства в соответствии с политикой Yandex Mobile Ads. Содержимое записей рекламному SDK не передаётся.

Pro-версия и лицензионный ключ

Активация и периодическая проверка Pro-лицензии обращаются к серверу лицензирования. Сам ключ не сохраняется в аналитике или отчётах о сбоях. Без сети Pro-статус продолжает действовать по последнему известному результату проверки.

Разрешения приложения

  • Микрофон — запись аудио.
  • Уведомления — постоянное уведомление во время фоновой записи (таймер, пауза/стоп).
  • Геопозиция (приблизительная и точная) — разовая привязка адреса к записи; необязательна.
  • Интернет — реклама, проверка лицензии, определение адреса, загрузка тайлов карты и загрузка моделей распознавания.

Хранение и удаление данных

Все записи и расшифровки хранятся локально и удаляются вместе с самой записью через интерфейс приложения или при удалении приложения с устройства. Отдельного серверного хранилища пользовательских записей у Fonic нет.

Дети

Приложение не предназначено для детей младше 13 лет и не собирает сознательно данные таких пользователей.
